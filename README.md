# Customer-Churn-analysis
📊 Churn Analysis
This project performs a detailed churn analysis for a telecom company, Tellico, aiming to uncover insights about customers who are likely to churn.

🔍 Key Focus:
Analyzing patterns and trends in churned vs. retained customers

Identifying key demographic and service-related factors influencing churn

Visualizing customer behavior and churn distribution

🛠 Tools Used:
Pandas & NumPy for data handling

Matplotlib & Seaborn for visualization

Jupyter Notebook for interactive exploration

📁 What’s Inside:
Data cleaning and preprocessing

Churn distribution and class imbalance check

Visual insights by gender, seniority, tenure, services, etc.

Heatmaps and correlation analysis

Scikit-learn (Logistic Regression, Decision Trees, etc.)

Jupyter Notebook for analysis and visualization

📁 Notebook Includes:
Data cleaning and preprocessing

Visual analysis of churn-related patterns

Feature selection and correlation analysis

Model training, evaluation, and performance comparison

✅ Ideal For:
Telecom analytics

Churn prediction modeling

Business strategy and customer retention planning
